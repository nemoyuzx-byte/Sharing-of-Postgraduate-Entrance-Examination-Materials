# 高数积分体系总图

面向高等数学与考研数学复习整理的单页竖版速查图，适合放大阅读、考前回顾和快速梳理各类积分之间的联系。

## 内容概览

- 定积分、二重积分与三重积分的计算方法和常见换元。
- 第一类、第二类曲线积分及其参数化计算。
- 第一类、第二类曲面积分及其投影计算。
- 格林公式、高斯公式与斯托克斯公式之间的转化关系。
- 质量、质心、转动惯量、做功和流量等常见物理模型。
