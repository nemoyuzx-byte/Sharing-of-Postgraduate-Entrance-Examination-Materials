# 408 数据结构：图的基本概念与常用推论

面向 408 数据结构复习整理的两页单栏速查资料。第一页按教材知识点顺序整理基本概念与定义；第二页按相同顺序补充书上标注和常用推论，书上手写内容使用下划线标记。

## 内容概览

- 有向图、无向图、简单图与多重图。
- 顶点的度、入度与出度，路径、回路与距离。
- 子图、连通分量与强连通分量。
- 生成树、生成森林、完全图、稠密图、稀疏图与有向树。
- 常考边数公式、连通性判断和树的等价判定。
